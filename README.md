# HisabBook – Daily Expense Manager (Native Android Project)

Package Name: `com.hisabbook.expensemanager`

## Quick Build Instructions

### Method 1: Build in 1 Minute via GitHub Actions (Direct APK Download)
1. Push this folder to a GitHub repository.
2. Go to **Actions** tab on your GitHub repository.
3. The `Build HisabBook APK` workflow runs automatically.
4. Download the generated `HisabBook-Installable-APK` artifact.
5. Tap and install on any Android phone!

### Method 2: Build in Android Studio
1. Open Android Studio (Hedgehog or newer).
2. Click **Open** and select this extracted directory.
3. Wait for Gradle sync to complete.
4. Click **Build** -> **Build Bundle(s) / APK(s)** -> **Build APK(s)**.
5. Transfer `app-debug.apk` or `app-release.apk` to your phone and install!
